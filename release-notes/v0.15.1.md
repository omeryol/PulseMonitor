## English

- **New “Plain” color palette** (Settings → Appearance → Color palette): every item uses the plain text color, so values switch between white and black automatically with the Windows taskbar theme. Turn off “Color by load” as well for a fully colorless look.
- Fixed: the weather alert level list in Settings → Alerts was cut off by long descriptions; what each level covers is now shown below the list.
- Screenshots refreshed for 0.15.
