## English

- Added a full weather-history view with quick periods from 7 days to 20 years, same-period previous-year comparison, seasonal summaries, temperature and rainfall charts, and colour-coded daily cards.
- Long historical weather requests are cached locally for two days, so shorter ranges open quickly after a larger range has been retrieved.
- Double-click the weather column to open the selected location's weather history.
- Added the optional Analytics panel visual style while preserving the Classic layout.
- Charts now show season bands by date, contextual hover cards, and fixed non-zooming interaction. Summary and season cards use the available window width efficiently.
- Release build dependencies are pinned to exact revisions for a more reproducible build.
