## English

- The taskbar panel now measures the real Start button position and shrinks when needed, preventing overlaps with centered taskbar icons.
- When taskbar icons move from left-aligned to centered, PulseMonitor asks whether to move the panel to the left. The themed prompt clearly shows both directions.
- Traffic history now follows the selected app theme and upload/download colour palette.
- Completed translations for all supported languages and updated the test platform.
