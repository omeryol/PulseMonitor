## English

- The CPU and RAM detail card now shows the five apps using the most processor and memory. Processes with the same name are combined into one row (e.g. chrome ×12).
- The memory list appears immediately; CPU values follow within half a second after a short loading indicator and refresh once per second.
- App rows use the CPU or RAM accent colour.
- Measuring runs only while the card is open and stops when it closes. Process information is never saved or written to the log.

## Türkçe

- CPU ve RAM ayrıntı kartı artık en çok işlemci ve bellek kullanan beş uygulamayı gösterir. Aynı adlı işlemler tek satırda toplanır (ör. chrome ×12).
- Bellek listesi hemen gelir; CPU değerleri kısa bir yükleme göstergesinin ardından yarım saniye içinde görünür ve saniyede bir yenilenir.
- Uygulama satırları CPU ya da RAM’in vurgu rengini kullanır.
- Ölçüm yalnızca kart açıkken yapılır, kart kapanınca durur. İşlem bilgileri kaydedilmez, günlüğe yazılmaz.
